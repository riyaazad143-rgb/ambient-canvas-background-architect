## 📐 The 7-Layer Visual Depth Protocol

Every background strictly adheres to a GPU-accelerated 7-layer architecture:

| Layer | Component | Implementation |
| :---: | :--- | :--- |
| **7** | **Micro-Particles** | Subtle twinkling dust & stars (`opacity: 0.15–0.4`) |
| **6** | **Kinetic Cruisers** | Moving jets, data packets, pulse beacons (`will-change: transform`) |
| **5** | **Anchor Modules** | Domain vectors (360° radar sweep, biometric laser, compass dial) |
| **4** | **Trajectory Curves** | Flow lines with `@keyframes flightFlowDash` (`stroke-dasharray`) |
| **3** | **Telemetry HUD** | Monospace technical stamps (GPS, airport codes, exchange rates) |
| **2** | **Texture Grid** | 60px–80px SVG dot-grid or circuit matrix overlay |
| **1** | **Ambient Glow Orbs** | Multi-layer blurred gradient circles (`filter: blur(80px–100px)`) |
